## Key Takeaways

- Recruiters want to see modern .NET: .NET 6/8, ASP.NET Core, Entity Framework Core and Azure. Lead with those, even if you also maintain older .NET Framework code.
- Write ".NET" and "C#" exactly as the ad does. ATS filters match the literal text, and "dotnet" or "C Sharp" can score differently.
- Migration work - .NET Framework to .NET 8, on-prem to Azure - is one of the most valued bullets you can have. Make it specific.
- Pair every framework name with what you built and what it changed.

A .NET developer resume gets read when the first third shows you work in current .NET - ASP.NET Core APIs, EF Core, Azure - with numbers on the systems you built. Many .NET developers maintain legacy code too, and that's valuable, but it should support the story, not lead it.

## What the job ad is really asking for

| Job ad says | What it means for your resume |
|---|---|
| "C#, .NET 6+ / ASP.NET Core" | Name the version you worked in and what you built with it. |
| "Entity Framework / SQL Server" | One bullet on data modelling or query performance. |
| "Azure (App Service, Functions, Service Bus)" | Name the Azure services, not just "Azure". |
| "Experience modernising legacy applications" | A migration bullet with before/after numbers. |

## Common Mistakes

1. **Only legacy versions on the resume.** If you've used .NET 6+, say so explicitly.
2. **"Microsoft technologies" as a skill.** Too vague to match any filter.
3. **No testing.** Senior .NET ads almost always mention unit tests.
4. **Listing every Azure service.** List the ones you configured or built against.

## Frequently Asked Questions

### Should I write ".NET" or "dotnet" on my resume?
Use ".NET" and "C#", the standard spellings. Most job ads use them, and ATS filters often match the literal text.

### How do I present mostly legacy .NET Framework experience?
Lead with the parts that transfer - C#, SQL Server, architecture decisions and business impact - then show any modern .NET exposure from side projects or upgrades. A migration you led, even a small one, is a strong bullet.

### Is a .NET developer resume different from a C# developer resume?
In practice they are the same role. Use whichever title the job ad uses in your headline, and keep both ".NET" and "C#" in your skills.
